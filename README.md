# HOWDI

HOWDI is a private multi-service ecosystem being built around commerce, local services, learning, community and internal financial control.

## Core Platforms

- HOWDI Shop
- Works / Service Professionals
- Vendor Portal
- HOWDI Connect
- HPay Control
- Payments
- Learn & Earn
- Admin

## Current Development Snapshot

Latest backend: **V19.0 Learn & Earn Course Studio** (11 September 2026).

Payments + HPay internal architecture is frozen at V18.5 pending future real payment/bank-provider integrations. Logistics is frozen at V15.0 unless a real production bug requires a change. Current product work is moving into Learn & Earn.

Learn & Earn is designed around:

> **Learn → Practice → Prove → Create → Earn → Grow**

Crochet is the first learning vertical, with future expansion planned for other handmade skills, service skills, digital skills and job-readiness pathways.
